# Portfólio — Fernanda Theodoro Casali

Portfólio pessoal em estilo **TikTok** (feed vertical com _scroll-snap_), com animações fluidas,
transições suaves e alternância de idioma **PT / EN**.

🎯 **Foco:** Análise de Dados · Business Intelligence · Engenharia de Dados

## ✨ Recursos

- Feed vertical full-screen com _snap scroll_ (igual TikTok "Para Você")
- Barra de ações lateral (curtir, comentar, compartilhar, CV) + disco giratório
- Fundos com gradientes animados e _grain_
- Animações de entrada por seção (IntersectionObserver)
- Indicadores de progresso e barra superior
- Botão de curtir com explosão de corações + _double-tap_ pra curtir
- Compartilhamento nativo (Web Share API) com _fallback_ pra copiar link
- Toggle de idioma Português / Inglês
- 100% responsivo, sem dependências externas (só Google Fonts)

## 🚀 Como rodar

É um site estático de arquivo único. Basta abrir o `index.html` no navegador.

### Publicar no GitHub Pages

1. _Settings_ → _Pages_
2. _Source_: branch `main` (ou a branch de deploy), pasta `/root`
3. Pronto — o site fica em `https://<usuario>.github.io/Portifolio/`

## 🛠️ Stack do site

HTML + CSS + JavaScript puro (vanilla). Fontes: Sora & Space Grotesk.
